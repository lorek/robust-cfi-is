# Offline g7 workflow

The public g7 identity is `g7_resnet`: a standard 62-dimensional normal input,
noise scale 0.2, and event threshold 5.157151232471544. Training seed 100,
K in {6, 16}, evaluation seeds 100 through 2000 by 100, and final-IS sample
size 100000 are recorded in `configs/paper/g7.yaml`.

Normal execution requires explicit paths to both external assets and an
explicit `cpu` or `cuda:N` event device. Before ResNet evaluation, the loader
checks filename-independent size and SHA-256 identities, safely loads the
prepared tensor with `weights_only=True`, validates its exact X/Y schema,
instantiates torchvision ResNet18 with `weights=None`, and strictly loads the
supplied state dict. It neither downloads nor examines a torchvision cache.

The required prepared tensor has SHA-256
`3eed840225285c10291673dea3a247504d6c225fd617648ba7b139ee5aa63c32`;
the required `IMAGENET1K_V1` state dict has SHA-256
`f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`.
Neither asset is redistributed here.

The exact first-24 selection, float16 conversion, X/Y-only schema
transformation, and serialization path for the required tensor have not been
fully established. The repository therefore does not provide or claim an
equivalent `prepare-g7` command. The earlier preparation script does not
exactly reproduce the required tensor; its status is
`DOES_NOT_EXACTLY_REPRODUCE`.

ImageNetV2 image redistribution and pretrained-weight redistribution require
separate rights review. Local use of user-supplied assets does not grant or
assert redistribution permission. CPU execution is supported for correctness
and offline validation; it is not advertised as the authoritative paper-speed
environment.
